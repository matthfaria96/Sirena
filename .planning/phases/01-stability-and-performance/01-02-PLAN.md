3. Add near `startSession`:
```swift
private static let frameQueue = DispatchQueue(label: "com.sirena.windowGestures.frame", qos: .userInteractive)

private func captureWindowFrame(for zone: WindowGestureZone) {
    guard let window = zone.window else { return }
    let windowID = window.id
    Self.frameQueue.async { [weak self] in
        let frame = window.currentWindowFrame()
        self?.thread.perform { [weak self] in
            guard let self, self.session?.zone.window?.id == windowID else { return }
            self.session?.windowFrame = frame
        }
    }
}
```
`session` stays confined to the tap thread because the write happens inside `thread.perform`. `previewFrame(for:)` already returns nil when `windowFrame` is nil, so until the frame arrives (typically well under one tick) the HUD shows no region preview; no other behaviour changes.
4. Do not edit WindowGestureExecutor.swift or WindowGestureZone.swift. Do not change the existing `tapDisabledByTimeout` re-enable handling.
